
# Student Center Dish Check

A web-based cafeteria menu management and information system for Strathmore University.

## 1. Project Overview

Student Center Dish Check is a web application designed to help students access daily cafeteria menu information without physically visiting the cafeteria.

The system allows students to view available meals, check prices, explore food details and see whether dishes are available or sold out.

It also provides an administrative platform for cafeteria staff to manage food items, update menu information and maintain accurate availability records.

## 2. Problem Statement

Students often have to physically visit the cafeteria to find out what meals are available, their prices and whether particular dishes are sold out.

This can be inconvenient and time-consuming.

Student Center Dish Check aims to address this problem by providing a centralized online platform where students can easily access updated cafeteria menu information.

## 3. Project Objectives

- Provide students with access to daily cafeteria menus.
- Display food prices and availability.
- Allow students to search and filter food items.
- Provide detailed information about meals.
- Allow students to submit anonymous food ratings.
- Enable authorized staff to manage daily menus.
- Provide administrators with control over system management.

## 4. Main System Features

### Public Features
- View daily cafeteria menus.
- Search for food items.
- Filter dishes by category.
- View food descriptions and prices.
- Check food availability.
- Submit anonymous food ratings.

### Staff Features
- Secure staff login.
- Add and update food items.
- Manage daily menu information.
- Update food availability.

### Administrator Features
- Secure administrator login.
- Manage food items and categories.
- Manage staff accounts.
- Manage cafeteria menu information.
- Access system management functions.
